Mulai menggunakan

Pasang stylesheet satu kali di bagian <head> template utama. Tidak diperlukan JavaScript untuk menampilkan ikon di aplikasi.

<link rel="stylesheet" href="https://carakadigitalmedia.github.io/caraka-icons/caraka-icons.css">

<i class="ci ci-tkk-berkemah" aria-hidden="true"></i>
<i class="ci ci-tkk-berkemah ci-2x" aria-hidden="true"></i>
Ukuran ikon

ci-xs, ci-sm, ci-lg, ci-xl, ci-2x, ci-3x. Ukuran mengikuti font jika helper ukuran tidak digunakan.

Tambah ikon baru

Upload file WebP ke folder icons/, commit, lalu tunggu workflow Actions selesai. Nama file menjadi class, misalnya tkk-memasak.webp → ci ci-tkk-memasak.
