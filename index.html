Mulai menggunakan

Tambahkan stylesheet library ke halaman Anda, lalu gunakan class ikon.

<link rel="stylesheet" href="https://USERNAME.github.io/caraka-icons/caraka-icons.css">

<i class="ci ci-tkk-berkemah" aria-label="TKK Berkemah"></i>

Ganti USERNAME dengan nama akun GitHub Anda. Ukuran ikon mengikuti ukuran font; gunakan ci-lg, ci-xl, atau ci-2x untuk mengubahnya.
