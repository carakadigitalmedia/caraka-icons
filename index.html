Mulai menggunakan

Tambahkan stylesheet Caraka Icons ke bagian <head> website Anda. Tidak perlu menyalin gambar ikon ke setiap proyek.

<link rel="stylesheet" href="https://carakadigitalmedia.github.io/caraka-icons/caraka-icons.css">

Gunakan class ikon di HTML:

<i class="ci ci-tkk-berkemah" aria-label="TKK Berkemah"></i>

<!-- Ukuran lebih besar -->
<i class="ci ci-tkk-berkemah ci-2x" aria-label="TKK Berkemah"></i>

Ikon mengikuti ukuran font secara default. Gunakan ci-xs, ci-sm, ci-lg, ci-xl, ci-2x, atau ci-3x untuk mengubah ukuran.

Contoh untuk CodeIgniter 3

Pasang stylesheet satu kali di template utama, misalnya application/views/templates/header.php, lalu gunakan class ikon di view mana pun.

<link rel="stylesheet" href="https://carakadigitalmedia.github.io/caraka-icons/caraka-icons.css">

<a href="<?= base_url('kegiatan'); ?>" class="btn btn-success">
  <i class="ci ci-tkk-berkemah" aria-hidden="true"></i>
  Kegiatan Berkemah
</a>
